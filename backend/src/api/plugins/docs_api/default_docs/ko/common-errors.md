
### 5. 일반적인 에러 응답

HTTP 코드 및 문제 해결은 전용 페이지에서 통합 관리합니다.

👉 **[게이트웨이 공통 오류 코드 및 문제 해결]({{error_codes_href}})**

**요약**（상세는 전용 페이지）：

| 코드 | 의미 |
| :---: | :--- |
| **402** | 잔액 부족（**429 아님**） |
| **400** | 잘못된 요청 / 콘텐츠·저작권 필터 |
| **429** | RPS/RPM 제한, 저잔액 진행 중 상한 |
| **403** | 토큰 권한（콘텐츠 필터는 400） |
| **200 + `status: failed`** | 비동기 영상 등 비즈니스 실패（폴링 시） |

> 오류 설명은 `error-codes` 전용 페이지만 수정합니다.
