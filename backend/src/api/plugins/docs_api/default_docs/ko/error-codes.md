# 게이트웨이 공통 오류 코드 및 문제 해결

HTTP 상태 코드는 **호출 로그 `status_code`와 일치**합니다. 잔액 부족은 **402**, 429는 속도 제한·진행 중 태스크 상한입니다. 상세는 [中文 (zh)] 또는 [English (en)] 참고.

| HTTP | 주요 용도 |
| :---: | :--- |
| 400 | 파라미터 / 유형 불일치 / **콘텐츠·저작권 필터** |
| 401 | 인증 실패 |
| **402** | **잔액 부족** |
| 403 | 토큰·IP·모델·할당량（정책은 400） |
| 404 | 업스트림 채널 없음, 또는 `status 404` |
| **429** | **RPS/RPM**, 저잔액 진행 중 상한 |
| 500/502/504 | 내부 / 업스트림 / 타임아웃 |

비동기 작업은 HTTP 200 + `status: failed`일 수 있습니다.
