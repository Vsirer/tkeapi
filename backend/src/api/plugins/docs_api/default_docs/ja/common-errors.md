
### 5. 一般的なエラー応答

HTTP コードとトラブルシューティングは専ページに集約しています。

👉 **[ゲートウェイの一般的なエラーコードとトラブルシューティング]({{error_codes_href}})**

**早見表**（詳細は専ページ）：

| コード | 意味 |
| :---: | :--- |
| **402** | 残高不足（**429 ではない**） |
| **400** | 不正リクエスト / コンテンツ・著作権 |
| **429** | RPS/RPM 制限、低残高時の在途上限 |
| **403** | トークン権限（コンテンツフィルタは 400） |
| **200 + `status: failed`** | 非同期動画等の業務失敗（ポーリング時） |

> エラー説明の更新は専ページ `error-codes` のみ行い、各例の末尾はリンクのみ。
