# ゲートウェイの一般的なエラーコードとトラブルシューティング

HTTP ステータスコードは **呼び出しログの `status_code` と一致** します。残高不足は **402**、429 はレート制限・在途タスク上限です。詳細は中国語 [中文 (zh)] を参照してください。

| HTTP | 主な用途 |
| :---: | :--- |
| 400 | パラメータ / 種別不一致 / **コンテンツ・著作権フィルタ** |
| 401 | 認証ヘッダー・API Key 不正 |
| **402** | **残高不足** |
| 403 | トークン無効、IP/モデル制限、クォータ（ポリシーは 400） |
| 404 | 上流チャネルなし、または `status 404` |
| **429** | **RPS/RPM**、低残高時の在途上限 |
| 500/502/504 | 内部 / 上流 / タイムアウト |

非同期タスクは HTTP 200 のまま `status: failed` となる場合があります。

## 6. 能力別補足（例と共有）

| 能力 | 典型 | コード / 注 |
| :--- | :--- | :--- |
| **千問画像** | `size` 不正、参照 URL 無効 | **400** |
| **万相動画** | 首尾フレームと参照素材の混在、音声のみ | **400** |
| **万相動画** | `files`/`links` と首尾フレーム role の混在 | **400** |

新規シナリオは **`error-codes`** のみ更新。各例の付録はリンクのみ。
