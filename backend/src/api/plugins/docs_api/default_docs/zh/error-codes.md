# 网关常见错误码与排查

使用 API 网关调用大模型时，失败响应由 **HTTP 状态码** + **JSON 错误体** 组成。对外 HTTP 码与控制台「调用日志」中的 `status_code` **一致**，便于按 `log_id` 追溯。

---

## 1. 统一错误响应格式

### 平台本地拦截（鉴权、余额、频控等）

```json
{
  "error": {
    "message": "账户余额不足0.5元",
    "type": "api_error",
    "code": "402"
  }
}
```

| 字段 | 说明 |
| :--- | :--- |
| `error.message` | 失败原因（上游错误会对 URL 域名、`sk-` 密钥脱敏） |
| `error.type` | 平台拦截时为 `api_error` |
| `error.code` | **HTTP 状态码字符串**（如 `"402"`），非 OpenAI 语义码 |

### 上游透传

上游返回合法 JSON 时，错误体可能 **原样透传**（含厂商自定义 `type` / `code`），HTTP 状态码仍与日志 `status_code` 对齐。

---

## 2. 状态码速查

| HTTP | 含义 | 典型 `message` |
| :---: | :--- | :--- |
| **400** | 参数非法、模型类型不匹配、**内容风控/版权拦截** | 参数错误；`PolicyViolation` / `OutputVideoSensitiveContentDetected` / 版权限制 |
| **401** | 鉴权失败 | `Missing Authorization Header` / `Invalid Bearer Token Format` / `Invalid API Key` |
| **402** | **账户可用余额不足** | `账户余额不足…` / `余额不足` |
| **403** | 令牌/IP/模型白名单等权限不足 | `Token disabled` / `Model xxx not allowed for this token` / `今日额度已耗尽` / `IP x.x.x.x not whitelisted` |
| **404** | 模型不存在、未配置渠道、无可用渠道，或上游资源不存在 | `模型不存在: xxx` / `模型未配置渠道: xxx` / `模型无可用渠道: xxx`；文案含 `status 404`（如输入图下载失败） |
| **429** | **频控或在途任务上限** | `RPS limit exceeded` / `RPM limit exceeded` / `当前余额较低，任务过多，请充值` |
| **500** | 网关内部异常 | `Internal server error` |
| **502** | 上游不可用 / 连接失败 | `Upstream request failed` 或上游原文 |
| **504** | 超时 / 网关中断 | 含 `timeout`、`gateway` 等 |

> **易混**：余额不足 → **402**；内容风控/版权 → **400**；令牌无权限 → **403**；**429** 仅表示 RPS/RPM 或低余额在途门禁。

---

## 3. 分场景排查

### 400 Bad Request（请求格式 / 类型错误 / 内容拦截）

* **诱因**：JSON 非法、缺必填字段、在聊天接口调用图片/视频模型；或上游内容安全/版权/敏感策略拦截（如 `PolicyViolation`）。
* **排查**：核对 `model` 与路径；校验 JSON。风控类请调整 prompt 或参考素材，**不是** 令牌权限问题（权限见 403）。

### 401 Unauthorized（鉴权失败）

* **诱因**：未带 `Authorization`、Bearer 格式错误、Key 不存在。
* **排查**：`Authorization: Bearer sk-xxx`（一个空格）。禁用/过期令牌返回 **403**。

### 402 Payment Required（余额不足）

* **诱因**：可用余额不足以覆盖预扣或最低消费。
* **排查**：控制台充值。异步任务 **GET 轮询 / DELETE 取消** 在超额时仍可放行，**POST 提交** 会被拦截。

### 403 Forbidden（权限 / 令牌配额）

* **诱因**：
  - 令牌禁用（`Token disabled`）、过期（`Token expired`）
  - 模型不在令牌白名单（`Model xxx not allowed for this token`）
  - IP 不在白名单（`IP x.x.x.x not whitelisted`）
  - 令牌日/周/月/总额度耗尽（`今日额度已耗尽` 等）
  - 创作中心专用令牌在非 Playground 环境调用
* **排查**：检查令牌开关、模型/IP 白名单与额度。内容审核/版权拦截是 **400**，不是 403。

### 404 Not Found（模型 / 渠道 / 资源不存在）

* **诱因**：`模型不存在`（模型表无此 ID）；`模型未配置渠道`（模型已建但渠道未绑定）；`模型无可用渠道`（已绑定但当前分组/额度/状态/HA 均不可用）；或上游明确返回 `status 404`（如输入图 URL 无法下载）。
* **排查**：先看错误文案是哪一种，再核对模型 ID、渠道绑定与用户分组；检查请求里的图片/视频 URL 是否可访问。

### 429 Too Many Requests（频控 / 在途限制）

* **诱因**：令牌 `rps_limit` / `rpm_limit` 超限；余额较低时同类异步在途任务达上限。
* **排查**：指数退避重试；充值或减少并发异步任务。

### 500 / 502 / 504（网关或上游异常）

* **502**：上游 HTTP 非 2xx、连接失败；非标准业务码会规范化为 502。
* **504**：连接或生成超时。
* **500**：平台内部错误（客户端只见通用文案，详情在服务端日志）。
* **排查**：稍后重试；HA 组会自动切换子渠。对照调用日志中的 `error_message`。

---

## 4. 异步任务特殊说明

视频等长任务：**提交与轮询** 传输成功时 HTTP 可为 **200**，业务成败看 body 中 `status`：

```json
{
  "id": "video_task_xxx",
  "status": "failed",
  "error": { "message": "上游失败原因" }
}
```

日志 `status_code` 记录推断的 4xx/5xx，轮询接口本身仍可能为 200。请以 `status` 与日志为准。

---

## 5. 日志追溯与 HA 说明

1. **日志**：每次请求写入 `log_id`、`status_code`、`error_message`、耗时与扣费；失败排查时按时间与 `log_id` 检索，HTTP 码应与 `status_code` 一致。
2. **HA 自动换路**：多渠道路由下，502/504 等可触发备用渠道重试，对调用端可能表现为一次成功或最终统一错误码。
3. **处理中状态**：异步提交成功后日志可能短暂为 `status_code=0`（处理中），轮询完成后更新为终态。

## 6. 按能力补充（示例专页共用）

以下场景在「常用调用示例」各文档中也会遇到，**统一在此维护**：

| 能力 | 常见表现 | 对应码 / 说明 |
| :--- | :--- | :--- |
| **聊天** | 上下文过长、参数不合法 | 上游可能透传 OpenAI 风格 `error`；平台拦截仍为 `api_error` + HTTP 码 |
| **图像** | 模型类型与 `/v1/images/generations` 不匹配 | **400**；多图/参考图参数错误同理 |
| **千问图像** | `size` 格式错误、参考图 URL 无效 | **400**；`1024x1024` 可写，网关会转为 `1024*1024` |
| **视频（异步）** | 提交成功但轮询 `status: failed` | 轮询 HTTP **200**；日志 `status_code` 为 4xx/5xx，见第 4 节 |
| **万相视频** | 首尾帧与参考素材混用、仅传音频无图/视频 | **400** |
| **万相视频** | `files` / `links` 与首尾帧 role 混用 | **400** |
| **视频（同步拦截）** | 余额、频控、无渠道 | **402 / 429 / 404** 等与上表一致 |
| **原生路由** | DashScope / 火山等路径拼写错误 | **404** 或上游 **400**；确认路径与模型上架名 |
