
### 5. 常见错误码与问题排查

HTTP 状态码、错误体格式及分场景排查已 **统一维护** 于专页，避免与各调用示例重复不同步。

👉 **[网关常见错误码与排查]({{error_codes_href}})**

**速记**（详情见专页）：

| 码 | 含义 |
| :---: | :--- |
| **400** | 参数非法 / 内容风控或版权拦截 |
| **402** | 账户余额不足（**不是** 429） |
| **429** | 令牌 RPS/RPM 限频，或低余额在途任务过多 |
| **403** | 令牌/IP/模型权限（余额见 402；内容拦截见 400） |
| **200 + `status: failed`** | 异步视频等长任务的业务失败（轮询时常见） |

HTTP 响应码与控制台调用日志 `status_code` 一致，可按 `log_id` 追溯。

> **维护约定**：新增或调整错误说明时，请只更新专页 `error-codes`；本附录通过链接自动指向最新内容。
